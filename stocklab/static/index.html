DATA / CHECK BEFORE RESEARCH

資料檢查與研究依據

匯入明示交易日曆

CSV 逐日列出 date,is_open（0 休市／1 開市），可加 reason。包含休市日，不以星期一到五猜測開市。

匯入不等於官方驗證；請自行核對來源、歷史修訂與商品市場身分。

檢查一份價格資料

比對開市日缺價、休市日多價、日曆範圍、跳價與零量；可能的停牌需另取得證據，不能自動補值。

使用此價格／事件版本最近明確檢查的報告；不會以較早通過的報告蓋掉新問題。新價格須重新檢查；此選項不代表完整資料認證，也不適用每日更新排程／關聯工作。

尚未選定檢查報告。未檢查的資料仍可能缺交易日或公司行動，請保留探索性解讀。

DATA / CORPORATE ACTIONS

股利與拆股事件

搭配原始價格，匯入已查核的公司行動。事件綁定價格版本；不得套用到已還原價格。這不等於事件完整性已驗證。

CSV 格式與帳務假設 
ex_date,kind,announced_date,cash_per_share,pay_date,split_ratio
2024-01-03,dividend,2023-12-20,2.5,2024-02-01,
2024-06-03,split,2024-05-01,,,4

以上是假設格式，不是市場資料。dividend 金額為事件前每股現金；split 是新股數／舊股數。股利除息日認列應收，付款日才可動用，不自動再投資；拆併股產生零碎股會停止。暫不含股票股利、減資退款或股利個人稅費。使用事件時，價格條件採含息指數口徑，成交仍用原始價格。每日自動更新目前不自動沿用手動事件。

探索候選條件

滾動樣本外驗證

固定均線候選，至少兩個不重疊測試段。每段獨立資金與期末平倉；沒有合格條件時保留現金，不拼成複利績效。

04 / AUTOMATION

讓程式持續工作

每日更新與批次研究

儲存時採用目前選取資料與成本。CSV 只研究、不自動更新。週一至五執行，假日由資料來源回應無新資料。需主機與 APP 持續運行；開發環境不保證全天運作。本地備份不防主機或磁碟整體遺失，異地備份仍需設定。

不中斷的研究脈絡

  • 零逐次 AI 成本下載、指標、回測及排程完全由本地 Python 執行。
  • 工作與資料版本保存程序重啟後可重新領取中斷工作；相同版本與參數直接沿用既有工作。
  • 跨電腦，連同一個研究主機正式部署仍需固定主機、登入／HTTPS 與異地備份；目前僅在本機介面啟動。
  • 延續開發，不重讀全部資料CLI context 會產生精簡狀態摘要；程式不會自動開新聊天或消耗模型 API。
