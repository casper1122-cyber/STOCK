# 自動化與節省 Token

## 已實作

- 不依賴 LLM：價格運算、條件比較、研究及每日排程由 Python 完成。
- 原始資料留在本地持久磁碟；聊天、Sheets 與 Git 都不需要接收完整資料。
- 增量抓取、不可變版本、指紋稽核、同資料／參數結果快取。失敗不會換成合成資料。
- SQLite 持久工作佇列，單一 worker 領取。中斷後重做未完成的商品，不重做已完成部分。
- 每個工作完成自動產生 `.stocklab/CONTEXT.md`。程式還沒執行時可用 CLI context 更新。
- `/api/jobs/{id}/summary` 只回傳最多 10 組摘要；完整曲線與成交紀錄按需下載。
- 瀏覽器每四秒讀取短工作列表，視窗隱藏時停止輪詢，不呼叫模型。
- 台北時間平日排程，每日同設定只建立一次；新機器恢復後需重新啟動 APP／worker。
- 本地中文條件助手不呼叫模型；預覽、追加修改、確認及回測結果在主機保存，重開頁面可接續。
- PWA 只快取應用殼；研究／聊天 API 明確 no-store，不以離線快取當成最新資料或持續運算能力。
- 免費雲端暫存模式停用排程；持久快取與續跑僅在資料仍保留時成立。要穩定保存與排程，可用自己的電腦。

這些節省的是模型輸入／輸出與不必要的運算，並不是讓雲端主機、資料授權或聊天開發免費。
若某天市場無新資料，沿用計算快取；供應商修訂舊資料時須重新下載完整區間建立新版本。

## 助理接續開發

1. 用同一份 GitHub 程式碼及持久資料磁碟，讀 AGENTS.md → docs/STATUS.md → 短 context。
2. 只讀當次相關模組；使用具體測試、局部搜尋，避免把全市場 CSV 或歷史聊天當上下文。
3. 設計或程式改變時計入引擎版本，避免誤用舊快取；成果與限制寫入 STATUS。
4. 不需要為每天例行作業開聊天。不會自動建立新聊天；平台沒有提供這種可保證的操作介面。

## Google Apps Script

`integrations/GoogleAppsScript.gs` 提供 Google Sheets 選單：提交研究、更新資料、讀取短摘要。
它不是 Python 執行環境，也不會代管長時間回測。
需要先部署可達的 HTTPS 研究主機，設定主機環境變數 STOCKLAB_API_TOKEN；
再於 Apps Script 的指令碼屬性安全設定 STOCKLAB_URL、STOCKLAB_TOKEN、STOCKLAB_DATASET_IDS。
程式只操作名為「研究摘要」的工作表；不會寄信、發交易指令或自動建立觸發器。
尚未連接 Google 帳號，沒有驗證 Apps Script 真實執行環境。它是可選入口，不影響 APP 的內建排程。

## 插件、Skills、連結器的取捨

Python 套件適合運算，Skills／AGENTS.md 適合接續工作，GitHub 適合版本保存，
資料 API 適合可稽核行情。通用聊天／文件連結器不會自動提高市場資料品質，也不能替代授權行情。
第一版不安裝多餘插件；確認具體通知、文件或資料需求後再接入，以免多出操作與 Token 消耗。
