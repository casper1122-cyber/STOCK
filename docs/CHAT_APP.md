# 對話式研究 APP（v0.3）

首頁先看候選條件、樣本量與研究摘要，再用研究對話欄提出假設。
這是本地規則解析的策略助手，不是通用模型，也不會在 APP 內修改程式或下單。
程式開發需求仍在目前的 Codex 對話提出；例行研究不需要消耗模型 Token。

## 使用方式

1. 在對話旁的資料選單選商品，或在文字中輸入已匯入的代號。
2. 輸入完整條件，檢查助理列出的規則、資料期間、價格／事件版本和成本。
3. 按「確認條件並開始」。工作保存到主機，完成後回覆勝率、筆數、淨報酬與回撤。
4. 可以追加「停損改成3%」「本金改成50萬」「手續費改成0.1%」「取消停損」。
   這會沿用上一組已解析的資料與條件，再產生新預覽；不會直接變更或重跑舊結果。
5. 按「查看完整報告與圖表」，可檢查權益、原始成交、股利帳務、來源與完整 JSON。

例句（商品必須已有資料，不會以合成資料替代）：

```text
0050，20日均線高於60日均線進場，20日均線低於60日均線出場，停損5%，本金100萬
RSI低於30進場，RSI高於70出場
收盤價突破20日均線進場，收盤價跌破20日均線出場
0050，找進場條件
0050，滾動驗證
0050，買入持有
```

未寫代號時使用資料選單／工作台勾選項目。多個來源同代號必須先選定一個版本。
進出場可用「且」或「或」，同一句混合邏輯會要求補充。
「高於」表示狀態；「突破」要求前一個收盤尚未高於、當日收盤才高於，下一觀測日開盤才成交。
目前均線支援 5、10、20、60、120 日，另含 RSI14、價格、成交量、量比與報酬／波動率欄位。
日期範圍、盤中、放空、停利、複雜組合等未支援文字會明確請使用者補充，不會忽略後執行。
候選搜尋與滾動驗證仍是固定 8 組均線，不把任意研究想法宣稱已完成搜尋。
v0.4 會在預覽時檢查指標暖機／研究最少筆數，並保留你在進階欄位設定的滾動長度。
可啟用手動研究日期／版本檢查要求；詳細範圍與風險統計定義見 [QUALITY_RISK.md](QUALITY_RISK.md)。

## 首頁條件觀察

- 最近 60 組目前引擎版本的候選研究，最多顯示 8 個不同證據組合。
- 以驗證段勝率排序；訓練和驗證各需至少設定的交易筆數，預設 10 筆。
- 同時顯示驗證段淨報酬、最大回撤、期間和來源；低樣本不會冒充高勝率策略。
- 測試段不參與排名；僅原研究已選策略才有測試段結果，其他候選不補算。
- 合成示範預設隱藏，開啟時有明確標籤。非示範資料也不等於來源已驗證。
- 反覆依此頁挑條件仍屬選樣，不能稱為未看過的樣本外證據或全市場最優策略。

## 像 APP 使用

已有手機底部導覽、聊天草稿保存、對話與工作在主機保存、PWA manifest、圖示及應用殼。
正式部署 HTTPS 研究室網址後，可依手機瀏覽器的「加入主畫面／安裝應用程式」使用。
目前只有本機瀏覽器／PWA 架構實測，尚未完成手機正式網址部署或實機安裝。
離線只開啟介面，不能離線研究；聊天、金鑰、資料與研究 API 不放進 service worker 快取。
瀏覽器只保存尚未送出的文字草稿，存取金鑰留在該分頁的 sessionStorage。

## 關掉網頁後

已提交的 APP 工作由主機上的 worker 執行。瀏覽器關閉不會取消它；前提是研究主機、資料磁碟與服務仍在運作。
本輪已實測工作 queued 時關頁，新頁重開後取得 done 與原對話。
這不代表 Codex 的開發任務永遠運行，也不代表你把個人電腦開著就能延長雲端工作區生命週期。
這次任務完成後不會無限自行開發；後續可用手機回到原對話繼續提出需求。
正式全天候資料更新仍需固定主機，見 DEPLOYMENT.md。
