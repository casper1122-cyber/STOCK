# 資料檢查與風險報告（v0.4）

目的是讓每個研究結果能說明：用了什麼資料、檢查到哪裡、尚缺哪些證據，以及結果有多不穩定。
目前仍沒有完整授權行情或官方交易日曆接入，不能稱為專業完整市場認證。

## 明示日曆與版本檢查

日曆 CSV 欄位 `date,is_open,reason`（reason 可省略），日期必須連續、遞增、不可重複，
包含休市日；is_open 僅接受 0／1。不能把「星期一到五」直接當成官方開市日。
來源、聲明市場、完整逐日內容與指紋一起保存；重新匯入同資料去重，但這不驗證來源真實性或授權。
不同市場、期貨交易日／日夜盤與歷史休市制度需另外核對，不能只看市場標籤。

對一份不可變價格版本選定日曆與可選的公司行動版本，檢查：

- 檔案指紋，以及資料庫期間／筆數是否與檔案一致。
- 日曆有沒有涵蓋整段價格期間。
- 開市日缺少價格、休市日多出價格，各自列明日期。
- 原始跳價、事件調整後仍超過 20% 的跳價及零成交量，列為複核旗標。
- 價格、事件、日曆與檢查報告各自的版本與指紋。

缺價可能來自停牌，也可能是缺資料；目前不自動補值或假設可以成交。
超過 20% 的跳價是人工複核門檻，不等於已確認錯價，更不是歷史漲跌幅合法性檢驗。
未提供日曆時狀態為 needs_calendar，不會當成通過。
passed_selected_checks 只表示指定的日期比對／指紋項目通過，其他複核項目與來源完整性仍未驗證。
零量、公司行動完整性、幣別、量的單位、盤中停牌、漲跌停、歷史母體及發布時點仍須另外處理。

## 手動研究的資料閘門

啟用「手動回測／聊天要求日期與版本檢查通過」後：

1. 價格與事件版本必須和檢查報告相符。
2. 報告須通過指定日期與指紋檢查；缺少報告或有日期問題便不執行。
3. 重新檢查舊日曆也會明確選定該報告，不能悄悄改用另一份通過報告。
4. 目前已知有問題時，不接受拿舊成功報告繞過；先核對來源並明確重新檢查。
5. 排隊後，worker 執行前仍再驗證，避免頁面檢查與實際執行不一致。

舊研究快照保存不改；若目前檢查發現問題，相關條件退出首頁排行，舊報告顯示新的問題提示。
重新執行同條件若資料／事件／檢查指紋相同可沿用快取，參數或版本改變會隔離結果。
每日更新產生新價格版本後需重新檢查，目前不自動沿用手動報告；關聯工作尚不支援此閘門。
這是手動研究選項，並非平台級監管或完整資料認證。

## 風險統計定義

|指標|定義與限制|
|---|---|
|勝率|淨損益大於 0 的完成交易／全部完成交易；平手計入總筆數但不算勝。包含模型期末結清。|
|95% 勝率描述區間|Wilson 區間，假設獨立同分布；未校正交易相依、資料選擇與多重搜尋，不是未來勝率保證。沒有交易不計算。|
|Profit factor|正淨損益總和／負淨損益絕對總和；尚無虧損時不輸出無限大，另標明情況。|
|平均每筆淨損益|所有完成交易淨損益平均；金額採台幣模型，不能直接比較不同資金規模。|
|平均每筆報酬|每筆淨損益／進場總成本的平均，不是組合日報酬或複利報酬。|
|平均獲利／虧損、payoff ratio|分別平均正負淨損益；平均獲利／平均虧損絕對值，無相應樣本不硬算。|
|最長連虧|連續淨損益小於 0 的交易數，平手會中斷。|
|最長回撤期間|權益低於先前高點的最長連續觀測日，包含期初資金高點；缺資料會影響解讀。|
|期末尚未恢復|最後仍低於先前高點，只陳述已知狀態，不推估何時恢復。|
|年化波動率|日報酬樣本標準差 × √252；短樣本、缺值和非同步交易需另行評估。|
|Sortino|平均日報酬／下行均方根 × √252，下行以全部觀測日、最低可接受報酬 0 計；無下行不輸出無限大。|
|Calmar|年化報酬／最大回撤絕對值；無回撤不硬算，短期年化不穩定。|

交易損益包含已取得但尚未付款的股利權利；不是全部已收現金，也不是券商正式對帳單。
沒有做股利個人稅費、券商逐筆取整、成交容量或完整交易制度模擬。
首頁依驗證段勝率排序，描述區間不參與排序；測試段仍不參與選擇。沒有因新增統計就宣稱找到了交易優勢。
