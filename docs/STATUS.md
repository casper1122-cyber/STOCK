# 開發狀態

使用者目標：個人使用、完整台灣金融商品及關聯市場研究、自訂條件與候選搜尋、
自動化、省 Token、不同電腦接續操作。品質與資料完整性優先，不能以不完整回測宣稱專業金融等級。

## 本輪建置

- Python／FastAPI＋SQLite；繁體中文 UI；CSV 結構驗證與不可變指紋資料版本。
- FinMind 原始日線下載器與增量更新；此環境來源連線未完成驗證。
- 股票／ETF 現股日線引擎，含成本、次日開盤、收盤觸發停損、交易紀錄與含成本基準。
- 自訂多條件、固定均線候選探索、60/20/20 時間切分；同期／滯後關聯為探索用途。
- 單一持久 worker、重啟續跑、資料／計算快取、每日排程、短摘要、完整 JSON 匯出。
- 可選 Apps Script 範本（尚未部署到 Google）、多電腦固定主機部署說明。
- 沒有 LLM API 調用、沒有交易下單、沒有推送 GitHub 或購買／部署雲端資源。
- 35 項測試通過；HTTP、Chromium 桌面／手機、服務重啟與備份還原已實測，見 VERIFICATION.md。
- 專案內提供 `.agents/skills/taiwan-stock-research/SKILL.md`，供後續任務重用有界摘要與研究檢核流程。
- 環境草稿已保存 install_script、start_skill、FinMind 網域；尚未套用網路或發布，真實請求仍為代理 403。

## 手機部署準備

- 新增 production 啟動入口：要求強通行碼、HTTPS 來源、指定資料路徑及背景 worker，讀取平台 PORT。
- Render 常駐付費／免費體驗設定已備妥，未建立或購買主機；免費模式僅合成資料，禁止匯入私人行情／啟用排程。
- 手機可見的通行碼對話框，已用隔離服務實測錯碼拒絕及正確登入；不是正式公開網址。
- 112 項測試通過；部署平台帳號、實際費用確認、GitHub 平台授權與公開 HTTPS 部署仍待外部操作。
- GitHub 原生 Git 的指定儲存庫讀取及部署分支 dry-run 通過；GitHub API 讀取被拒絕，未要求額外 token。

## 下一階段必須完成

1. 實際連通資料源、確認授權，取得全市場／歷史母體，完成跨來源及交易日曆稽核。
2. 完整公司行動來源與總報酬稽核，point-in-time 財報／籌碼／歷史 ETF 成分；目前僅處理手動提供的現金股利／拆併股。
3. 專用期貨逐合約交易引擎：日夜盤、到期、換月、乘數、保證金／強平；之後選擇權等商品。
4. 漲跌停與成交量限制、歷史費稅及逐筆取整、投資組合、連續持倉滾動部署、多重檢定與不確定性。
5. 固定主機、登入／HTTPS、備份復原、服務重啟及跨電腦實測；有多 worker 需求再改中央資料庫。
