# 免費在手機使用

2026-11-01 使用者已明確改為免費方案，取代先前常駐付費的偏好。
不購買主機、不訂閱行情或模型 API。計算、成本與資料檢查不因免費刪減；
免費來源缺少的歷史資料必須列為缺口，不能以合成資料替代。

目前沒有已部署的手機網址。GitHub 程式碼、開發工作區、截圖及環境「發布」都不是 APP 網址。

## 自己的電腦執行研究（建議）

電腦保存完整資料與工作佇列，不必租主機。手機透過私人 HTTPS 使用同一個 APP，
可加入主畫面；電腦與程式需持續運行，不能休眠。瀏覽器可以關閉。
Windows 使用 WSL Ubuntu；Linux 可直接使用，見 [免費個人主機](FREE_PERSONAL_HOST.md)。
這些步驟仍需在使用者電腦執行，目前沒有遠端控制使用者設備。

## 免費雲端：暫存研究

根目錄 `render.yaml` 已改成 `plan: free`，沒有付費磁碟、資料庫或收費服務。
使用 `STOCKLAB_EPHEMERAL_MODE=1`，可匯入真實 CSV、下載行情、對話設定條件及回測。
不自動建立合成資料；行情可用性、免費配額與完整性仍需實際驗證。

免費主機可能休眠，重新建立時資料可能遺失。無人排程停用，既有排程也不會自動啟動。
使用完請按 APP 上方「下載完整備份」，確認檔案保存到自己的裝置，並保留匯入的原始 CSV。
關閉頁面不代表備份已下載，也不能保證免費主機持續運算。

1. 用自己的 GitHub 帳號登入 https://dashboard.render.com/，授權 STOCK 儲存庫。
2. 建立 Blueprint，選擇 `codex/mobile-access` 分支及根目錄 `render.yaml`。
3. 確認方案為 Free、沒有付費磁碟或加購；若要求升級／付款就停止，不改成付費方案。
4. 部署成功後，平台提供的 HTTPS Web Service URL 才是手機 APP 網址。
5. 在平台安全設定查看自動產生的 STOCKLAB_API_TOKEN，存入密碼管理器，勿貼到聊天或 GitHub。
6. 手機開啟 APP、輸入研究室通行碼，再用瀏覽器的「加入主畫面」。

平台當時的免費條件與實際部署仍待驗證。官方網站目前受網路限制，本環境沒有平台登入權。
若平台不提供符合需求的免費方案，改用自己的電腦，不購買替代服務。
`deploy/render-preview.yaml` 保留為只含合成資料的測試版本，不是預設研究版。

## 備份與還原

備份包含一致性的 SQLite 快照與不可變行情檔：研究結果、對話、事件、日曆、檢查報告與設定都在資料庫內。
不包含服務通行碼、環境金鑰、鎖檔、日誌或過往備份。檔案未加密，含私人資料，請妥善保存。
下載完成後，伺服器清除此下載使用的臨時壓縮檔；API 與備份不進離線快取。

目前還原需在自己的 Linux／WSL 電腦用 CLI 執行，先停止研究服務並指定全新目錄；
**沒有手機一鍵還原或雲端重設後自動復原**。校驗與安全路徑檢查保留：

```bash
.venv/bin/python -m stocklab restore --archive /path/to/stocklab-backup.tar.gz --destination /new-empty-data
export STOCKLAB_HOME=/new-empty-data
bash scripts/start-personal.sh
```

正式手機連線、平台部署與使用者電腦設定仍待完成，本機測試不代表已上線。
