# 尚無訂閱時，如何選資料

優先完整性，先驗收再付費。以下是選型比較，不是已購買方案或已驗證的全市場涵蓋承諾。
沒有查證過的最新售價、各方案歷史深度、存取配額與授權條款不填猜測數字。

|選項|在此專案的定位|下決定前必須查證|目前證據|
|---|---|---|---|
|TWSE／TPEx／TAIFEX 等官方來源|權威核對、制度、交易日曆、公司行動、契約規格|各資料表歷史深度、格式、使用條款、下市／修訂與下載方式|已列來源與驗收計畫；尚未逐表接入|
|FinMind|優先驗證的整合 API，降低自行整合成本|付費方案是否含所需公司行動、下市母體、財報發布時點、期貨逐合約與歷史深度|已檢視官方 v4 用戶端、實作日線下載器；實際 API 連線仍被此環境網路政策擋住|
|TEJ／同類授權金融資料庫|完整性優先時的候選，需取得方案清單及樣本做驗收|point-in-time 與修訂政策、下市商品、歷史 ETF 成分、公司行動、資料字典與個人使用報價|僅確認官方 API 套件及服務入口；未取得訂閱、報價或樣本，不能宣稱覆蓋完整|
|券商行情 API，例如 Shioaji|日後即時觀察、券商相容性；不是取得完整研究母體的替代品|歷史資料留存、可用頻率、授權、帳戶要求與資料來源口徑|僅確認官方 SDK 與文件入口；未連券商帳號，無下單功能|
|CSV／自有歷史檔案|不綁平台的接入方式，可放授權資料與單一期貨契約|來源、使用權、日曆、還原方式、幣別、量的單位與時間戳|已可匯入並檢查結構，資料正確性仍需獨立稽核|

官方套件入口（本輪從 PyPI 公開 metadata 核對，不代表資料方案驗收）：

- FinMind：https://github.com/FinMind/FinMind
- TEJ API：https://api.tej.com.tw
- Shioaji：https://sinotrade.github.io/

## 建議的採購／接入順序

1. 先確認完整商品清單與資料字典，選股票、ETF、下市股票、除權息、分割及期貨換月各一組樣本。
2. 用官方紀錄核對樣本；計算含息／原始口徑差異，驗證公告時點、停牌與到期日。
3. 供應商必須回答：能否保留本地版本？個人自動回測是否符合授權？修訂如何追蹤？
4. 樣本通過後，再比較實際訂閱費、請求限制、儲存成本與可維護性；沒有必要一次買所有服務。
5. 可能採「授權歷史資料＋官方交叉核對＋API 增量更新」組合；實際供應商要依樣本證據決定。

目前不推薦把聊天外掛當行情資料庫，也不建議在尚無 point-in-time 與總報酬驗證前，
用更多候選條件或更多模型掩蓋資料缺口。
