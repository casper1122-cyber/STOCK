# 資料來源與完整性

「能下載一檔股票」不等於「有完整台灣金融市場」。每個資料集都必須能交代授權、來源、時間、修訂與價格口徑。
下表是接入與驗收計畫；未實作部分不能當成現有能力。尚未取得或驗證任何全市場授權資料。

|範圍|優先查核來源|目前狀態／需補的證據|
|---|---|---|
|股票、ETF 日 OHLCV|FinMind；TWSE／TPEx 交叉核對|FinMind 下載器已實作、欄位與失敗處理有模擬測試；此環境實際連線尚未通過|
|上市、上櫃、興櫃、下市母體|TWSE、TPEx；具歷史母體的授權供應商|未接入；需代號生命週期、下市報酬、歷史可投資範圍|
|交易日曆、停復牌、注意／處置|TWSE、TPEx|可手動匯入逐日日曆比對缺價／休市多價；官方來源驗證、停牌例外與處置制度未接入，不補缺值|

再決定方案；不要為了「資料很多」購買無法完成上述驗收的方案。

## 每一資料集的接入驗收

1. 商品識別：交易所、代號沿革、資產類型、幣別、上市／下市期間、期貨契約識別。
2. 時間：交易日、交易時段、時區、資料公開時刻、修訂時刻，避免偷看未公布資料。
3. 價格：原始／還原／含息、OHLC 調整一致性、公司行動對帳。
4. 完整性：官方日曆、停牌對照、重複、缺值、跳價、量值單位與跨來源抽查。
5. 可重現性：來源、拉取時間、查詢範圍、不可變版本、指紋與授權註記。
6. 實證：交易規則／成本與歷史制度、獨立前瞻或滾動驗證、多重搜尋偏誤、容量與風險。

目前完成第 5 項的本地版本機制及第 4 項的部分結構檢查；其他項目仍需依資料源與商品逐項實作。
