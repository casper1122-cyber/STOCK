# 台股研究室 · Taiwan Stock Lab

個人使用的台股研究 APP。Python 計算、SQLite 工作佇列、繁體中文瀏覽器介面。
**目前是可驗證的研究開發基礎，還不是涵蓋所有金融商品的專業資料／交易平台。**

目前採免費路線：自己的電腦保存研究，或使用會休眠／重設的免費雲端暫存版。
根目錄部署設定為 Free，沒有付費磁碟；手機入口與備份見 [免費手機使用](docs/PHONE_ACCESS.md)。

v0.3 已有對話式條件預覽／確認回測、追加修改、驗證段勝率觀察、研究摘要與可加入主畫面的 PWA 架構。
使用範例、能力範圍與關頁後行為見 [對話式研究 APP](docs/CHAT_APP.md)。
v0.4 加入日曆／版本檢查、手動研究品質閘門、勝率描述區間與擴充風險統計，見 [資料檢查與風險報告](docs/QUALITY_RISK.md)。

## 啟動（Linux、Python 3.12+）

```bash
cd /workspace/STOCK
bash scripts/setup.sh
bash scripts/start.sh
```

啟動後在執行這個程式的主機瀏覽器使用介面，預設埠 8000、僅綁定 loopback。
在自己的電腦長期研究可改用 `bash scripts/start-personal.sh`，自動設定本機通行碼；
Windows／WSL 與手機私人連線見 [免費個人主機](docs/FREE_PERSONAL_HOST.md)。
雲端 onboarding 不提供 localhost 預覽。跨電腦使用需要部署到固定主機，見 [部署與換電腦](docs/DEPLOYMENT.md)。
這裡的雲端工作區是開發環境，不保證全天候執行；也不是你正在操作的個人電腦。

## 工作流程

1. 下載 FinMind 台股／ETF 日線，或匯入自己的 CSV。
2. 查看來源、期間與品質資訊，勾選資料。股票、ETF 類型須正確指定。
3. 填入進場、出場、停損及成本；或搜尋固定 8 組均線候選。
4. 查看權益曲線、買入持有比較、成交紀錄與模型限制；JSON 匯出可保留完整研究證據。
5. 可儲存台北時間的每日更新／研究排程，主機與 APP 必須持續運行。
6. 原始價格可匯入現金股利／拆併股事件，回測會保存事件版本與帳務；也可執行滾動樣本外驗證。

CSV 格式：`date,open,high,low,close,volume`。日期為 YYYY-MM-DD 且遞增；volume 可省略，但不能使用成交量條件。
每個檔案只含一個商品、一種價格口徑、每天一筆；不可混合期貨不同到期合約或不同交易時段。
期貨、指數可匯入做關聯分析，**尚不能做交易回測**。

FinMind 需要允許 `api.finmindtrade.com`。有自己的授權時可在安全的環境設定提供 `FINMIND_TOKEN`，不必填在聊天或程式碼。
下載器採用官方 v4 API 與 Bearer header，不把金鑰寫入網址或報告；實際可用資料與配額依服務方案。
未搭配完整公司行動的原始資料不是含息報酬，不應據此推論 ETF 長期投資績效。

## 公司行動與成交對帳（v0.2）

在網頁「股利與拆股事件」匯入 CSV：
`ex_date,kind,announced_date,cash_per_share,pay_date,split_ratio`。
kind 為 dividend 或 split；股利金額定義為事件前每股現金，拆股比例為新股數／舊股數。
公告日期不得晚於事件日；事件必須對應價格中的觀測日，不能套用到已還原價格。
事件版本綁定不可變的價格版本，回測請求會保存使用的版本和指紋。

- 除息日以前持股者取得權利；當天開盤買入者沒有權利，當天開盤賣出者保留權利。
- 除息日認列應收，付款日或下一觀測日才轉現金；未付股利不會提前拿來買股，也不自動再投入。
- 權益包含應收股利；期末未付款項另外列示，不能把它當成已收現金。
- 拆股調整持股股數，保留原始進場成交價。initial_quantity 是進場股數，quantity 是出場股數。
- 產生零碎股時停止，不推測畸零股補償；股票股利、減資退款、個人股利稅費尚未支援。
- 使用事件時，條件的 OHLC 為因果含息指數口徑，成交用原始價格；價格數值條件需按此口徑設定。
- 本模型股利為稅前金額，未獨立驗證事件完整性、公告盤中時刻與事後修訂；不是券商正式對帳單。

## 不使用模型 API 的自動化

- 指標、條件搜尋、回測、關聯、排程都由 Python 執行；沒有 OpenAI 或其他 LLM 依賴。
- 資料不可變版本＋SHA-256 指紋檢查，相同匯入不重複保存。
- 每日下載從最後一筆的下一天開始；不重抓整段歷史。歷史修訂需明確重抓完整區間，以建立新版本。
- 相同資料、引擎版本與參數會沿用工作／計算結果，程序重啟可重新領取未完成工作並沿用完成部分。
- 每次工作完成自動更新 `.stocklab/CONTEXT.md`；助理先讀短摘要，不用讀完整股價或聊天紀錄。
- 不會自動開新聊天；目前聊天中的開發及需求討論仍使用 Token。
- 詳見 [省 Token 與自動化](docs/AUTOMATION.md)。

```bash
.venv/bin/python -m stocklab context   # 最多 30 組資料與最近五個工作
.venv/bin/python -m stocklab demo      # 明確建立合成資料，只測流程，不是行情
.venv/bin/python -m stocklab worker --once  # APP 未啟動時處理一個工作
.venv/bin/python -m pytest -q
```

資料、結果與排程在 `.stocklab/`，預設不進 Git。可用 `STOCKLAB_HOME` 指定持久磁碟。
部署平台需先能讀取 GitHub 中的程式；此雲端工作區不等於正式主機，也不是手機 APP 網址。
手機入口與部署準備見 [如何真的在手機打開](docs/PHONE_ACCESS.md)。

## 研究假設與尚缺能力

使用當日收盤資料產生條件，下一個觀測日開盤成交；做多、全資金、整股數、無槓桿。期末以收盤價結清。
手續費、最低手續費、賣出稅、滑價可設定。停損是前日收盤觸發，不是假設盤中能以門檻價成交。
每個商品獨立回測，並非投資組合；調整 OHLC 的成交金額也不是可核對的實際券商帳務。

候選研究：暖機 120 筆、剩餘資料依時間 60/20/20；訓練段排名前 3、驗證段選 1，測試段只算被選策略。
另有滾動驗證：預設 252 日訓練、63 日驗證、63 日測試，至少兩段；每段重新選擇，測試段不重疊。
每段獨立初始資金與期末平倉，不拼接成可直接交易的複利曲線；沒有合格策略的區段保留現金。
這仍是探索研究，尚無多重檢定校正、依賴性調整或獨立前瞻測試；新增勝率描述區間不能稱為已驗證的交易優勢。
反覆看測試段、跨商品挑績效，都會污染樣本外證據。

完整市場母體、下市商品、官方日曆、完整公司行動來源、股利自動再投資、歷史稅制、流動性／漲跌停成交限制、
財報發布時點、期貨換月／保證金、選擇權與權證模型仍未實作。
資料來源與專業研究的驗收條件見 [資料涵蓋計畫](docs/DATA_SOURCES.md) 和 [專案狀態](docs/STATUS.md)。
供應商選型見 [資料方案比較](docs/PROVIDER_COMPARISON.md)，本輪實測範圍見 [驗證紀錄](docs/VERIFICATION.md)。
